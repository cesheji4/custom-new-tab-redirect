# Custom New Tab Redirect · 去广告纯净版

把 Chrome / Edge 等 Chromium 浏览器的新标签页重定向到自定义网址的 Manifest V3 扩展。

**本仓库为去广告、纯净绿色、干净快速版**：移除了原版周期性弹出的推广落地页、倒计时与引导升级卡片，只保留「设置网址 + 直达跳转」核心功能。

## 特性

- **直达跳转**：新标签页立即打开已保存的网址，无中间落地页、无倒计时等待
- **去广告**：移除原版每 10 次新标签弹出的推广卡片（v2 版本推广、YouTube 教程链接）以及「一周内不再提醒」「重置推广」等按钮
- **绿色纯净**：无统计埋点、无捆绑、无额外申请权限
- **干净快速**：原生 HTML + 原生 JavaScript，无框架、无第三方依赖，体积小、加载快

## 安装

1. 下载并解压本仓库
2. 打开浏览器扩展页：Chrome 地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点「加载未打包的扩展程序」，选择本目录
5. 点工具栏扩展图标，在输入框填写目标网址并保存；之后新标签页将直接跳转过去

## 使用

- 点击工具栏扩展图标可修改或清空跳转网址
- 新标签页加载后立即跳转到已保存的地址，不再经过任何推广页

## 目录结构

```
├─ manifest.json       扩展清单（Manifest V3）
├─ homepage.html       新标签页落地页（未设置网址时显示设置表单）
├─ homepage.js         直达跳转逻辑
├─ popup.html          工具栏弹窗界面
├─ popup.js            弹窗保存 / 清空逻辑
└─ images/icon128.png  扩展图标
```

## 改造说明

- 保留原 `manifest.json` 中的 `key`，以维持原扩展 ID 不变。
